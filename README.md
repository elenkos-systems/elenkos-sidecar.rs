# elenkos-sidecar.rs

k8s sidecar for Elenkos Systems.

Inherits [`ores-otel-sidecar`](https://github.com/ores-otel/ores-otel-sidecar.rs).
Bind with `ELENKOS_SIDECAR_BIND` (default `127.0.0.1:9090`).

```sh
cargo run --bin elenkos-sidecar
```

Env keys are centralized in `.cli-flags.toml` and generated by `f2e generate` into `generated/{rust,dart,typescript,gleam}`.
